## v0.9.0 - 2026-10-15
### Added
* `repair` gains `--no-restore-attributes` ([#94](https://github.com/desertwitch/par2cron/pull/94))
### Changed
* `repair` now defaults to restoring attributes (ownership, mode, times) ([#94](https://github.com/desertwitch/par2cron/pull/94))
### Fixed
* `--purge-backups` and `--restore-backups` ignoring files in subfolders ([#94](https://github.com/desertwitch/par2cron/pull/94))
* bound parsed par2 packet lengths by remaining stream size ([#96](https://github.com/desertwitch/par2cron/pull/96))
* do not rebuild bundle index on transient I/O errors ([#97](https://github.com/desertwitch/par2cron/pull/97))
* do not reset bundle manifest on transient I/O errors ([#97](https://github.com/desertwitch/par2cron/pull/97))
* do not skip par2 packets on transient I/O errors ([#97](https://github.com/desertwitch/par2cron/pull/97))
* file handle leak on failed bundle open ([#97](https://github.com/desertwitch/par2cron/pull/97))
* possible endless scanning in bundle and par2 parsing ([#97](https://github.com/desertwitch/par2cron/pull/97))
* do not skip par2 packets on a stalled reader ([#97](https://github.com/desertwitch/par2cron/pull/97))
* allow cancelling par2 parsing on a stalled reader ([#97](https://github.com/desertwitch/par2cron/pull/97))
* stricter validation of file names when unpacking bundles ([#99](https://github.com/desertwitch/par2cron/pull/99))
* stricter unicode packet parsing to align with par2cmdline ([#100](https://github.com/desertwitch/par2cron/pull/100))
* do not skip packets using untrusted packet length ([#100](https://github.com/desertwitch/par2cron/pull/100))
* bundles not sorting index entries first ([#101](https://github.com/desertwitch/par2cron/pull/101))
* par2 root matching should be case-sensitive ([#101](https://github.com/desertwitch/par2cron/pull/101))
* create existence check should cover volumes ([#101](https://github.com/desertwitch/par2cron/pull/101))
* check existence before bundling operations ([#101](https://github.com/desertwitch/par2cron/pull/101))
* stricter filename validation before create jobs ([#101](https://github.com/desertwitch/par2cron/pull/101))
* `--skip-maybe-edited` should parse par2 (not just creation manifest) ([#103](https://github.com/desertwitch/par2cron/pull/103))
### Security
* bumped toolchain to `go1.27.2` ([#95](https://github.com/desertwitch/par2cron/pull/95))

## v0.8.0 - 2026-10-05
### Added
* `repair` gains `--skip-maybe-edited` to skip possibly edited PAR2 sets ([#91](https://github.com/desertwitch/par2cron/pull/91))
* `verify` now warns if corrupted PAR2 sets were possibly edited (newer mtimes) ([#91](https://github.com/desertwitch/par2cron/pull/91))
* `info` now reports jobs overdue for verification (by one run or a full cycle) ([#91](https://github.com/desertwitch/par2cron/pull/91))
* par2cron gains `list` command to show all par2cron-managed PAR2 sets and their status ([#91](https://github.com/desertwitch/par2cron/pull/91))
* par2cron gains global flag `--log-plain` to disable colored logs (also respects `NO_COLOR` environment variable) ([#92](https://github.com/desertwitch/par2cron/pull/92))
* `info` gains `--prometheus` to export Prometheus metrics ([#92](https://github.com/desertwitch/par2cron/pull/92))
* `bundle` gains `spec` subcommand to print the bundle specification ([#92](https://github.com/desertwitch/par2cron/pull/92))
* `config` gains `example` subcommand to print an example configuration ([#92](https://github.com/desertwitch/par2cron/pull/92))
### Changed
* `bundle info` command was renamed to `bundle debug` ([#91](https://github.com/desertwitch/par2cron/pull/91))
* times are now stored as UTC in manifests and JSON output ([#91](https://github.com/desertwitch/par2cron/pull/91))
* logs are now uncolored with full timestamps when output is not a terminal (e.g. cron, pipes, files) ([#92](https://github.com/desertwitch/par2cron/pull/92))
* example configuration has been moved to `docs/configs` folder ([#92](https://github.com/desertwitch/par2cron/pull/92))
* `check-config` command renamed to `config check` (now a subcommand of `config`) ([#92](https://github.com/desertwitch/par2cron/pull/92))
### Fixed
* resolved duplicate or missing `op` key in logs ([#91](https://github.com/desertwitch/par2cron/pull/91))
* resolved mangled global state in CLI command construction ([#91](https://github.com/desertwitch/par2cron/pull/91))
### Security
* bumped toolchain to `go1.27.1` and updated dependencies ([#91](https://github.com/desertwitch/par2cron/pull/91))
* changed deprecated yaml backend to `go.yaml.in/yaml/v3` ([#91](https://github.com/desertwitch/par2cron/pull/91))

## v0.6.0 - 2026-06-19
### Added
* `tool md5` gains `--all` to parse all provided files (not just PAR2 indexes) ([#76](https://github.com/desertwitch/par2cron/pull/76))
* `--seq-url` and `--seq-key` to send logs to a (remote) Seq logging server ([#80](https://github.com/desertwitch/par2cron/pull/80))
### Changed
* `tool md5` now defaults to parsing only PAR2 index files (optional `--all`) ([#76](https://github.com/desertwitch/par2cron/pull/76))
* PAR2 parsing now skips over unhandled packets instead of scanning through ([#74](https://github.com/desertwitch/par2cron/pull/74))
* Manifest write failure on `create` is now a job-fatal (partial failure) error ([#77](https://github.com/desertwitch/par2cron/pull/77))
### Fixed
* PAR2 operations now observe mid-I/O cancellation ([#78](https://github.com/desertwitch/par2cron/pull/78))
* Bundle operations now observe mid-I/O cancellation ([#77](https://github.com/desertwitch/par2cron/pull/77))
* Bundle `info` command taking very long to validate large bundles ([#75](https://github.com/desertwitch/par2cron/pull/75))
* PAR2 parsing taking very long to parse large files (such as bundles) ([#74](https://github.com/desertwitch/par2cron/pull/74))
* Command `tool md5` taking very long to parse large files (such as bundles) ([#76](https://github.com/desertwitch/par2cron/pull/76))
